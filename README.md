# ComfyUI-mscDev24

Custom nodes for [ComfyUI](https://github.com/comfyanonymous/ComfyUI).

## Installation

### ComfyUI Manager

1. Open ComfyUI Manager.
2. Select **Install via Git URL**.
3. Enter:

   `https://github.com/mscDev24/ComfyUI-mscDev24.git`

4. Install the repository.
5. Restart ComfyUI.

### Manual Installation

Clone the repository into the `custom_nodes` directory:

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/mscDev24/ComfyUI-mscDev24.git
